🎯 О проекте

NetDissector — это библиотека для работы с сетевыми протоколами уровней 2-4 модели OSI (Ethernet, IP, TCP/UDP и др.). Проект создан как инструмент для изучения сетевых технологий через практическую реализацию, но может использоваться и в реальных проектах. В планах использовать в своем сетевом анализаторе типа tcpdum
